# Privacy Policy / プライバシーポリシー — chronicle-studio

Last updated: 2026-08-22

## English

chronicle-studio ("the Client") is a private command-line application operated and
used solely by its developer to manage the developer's own YouTube channels.

**Use of YouTube API Services.** The Client uses the YouTube API Services. By using
the Client, the developer (its only user) agrees to be bound by the
[YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of
data is described in the [Google Privacy Policy](http://www.google.com/policies/privacy).

**Data the Client accesses.** The Client authenticates via OAuth 2.0 with the
developer's own Google account only. It accesses: (a) upload capability for the
developer's own channels (`videos.insert`, `thumbnails.set`), and (b) public
statistics and comments of the developer's own published videos (`videos.list`,
`commentThreads.list`). The Client does not access any data of third parties.

**Data storage.** Retrieved statistics and comments of the developer's own videos
are stored locally on the developer's personal computer as plain-text log files for
performance-trend tracking. No data is transmitted to, shared with, or sold to any
third party. No advertising or analytics services are used. The stored data can be
deleted by the developer at any time. OAuth tokens are stored locally on the same
computer and are never shared.

**No external users.** The Client is not distributed and has no users other than
the developer. Therefore it does not collect any personal information from any
person other than the developer.

**Revoking access.** API access granted to the Client can be revoked at any time
via Google security settings:
https://security.google.com/settings/security/permissions

**Contact.** kokihiroto2@gmail.com

## 日本語（要約）

chronicle-studio（以下「本クライアント」）は、開発者本人のみが利用する私的な
コマンドラインアプリケーションです。

- 本クライアントは **YouTube API サービス** を利用しており、利用にあたっては
  [YouTube利用規約](https://www.youtube.com/t/terms) が適用されます。Googleによる
  データの取り扱いは [Googleプライバシーポリシー](http://www.google.com/policies/privacy)

- 本クライアントがアクセスするのは、開発者本人のGoogleアカウントによるOAuth認証を

  読み取り」のみです。第三者のデータには一切アクセスしません。

  個人情報を収集することはありません。
- 本クライアントへのアクセス権は、Googleのセキュリティ設定
  （https://security.google.com/settings/security/permissions）からいつでも取り消せます。
